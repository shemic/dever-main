# Runtime performance P2

用户已批准继续上一阶段；本阶段完成同语义异步对照、高负载 HTTP/HTTPS 扫描和 TCP/WebSocket/SSE 有界长连接测试，并回答 HTTP/2 的接入条件。HTTP/2 实现留到下一阶段。

## 验收

- Rust 对照调用现有 Dever task runtime，保留 run/wait 的任务额度、结构化取消和清理；单独标注工作线程调度实验的边界。
- 复用 P1 构建、进程采样、cgroup 和报告逻辑，记录校验和、样本、CPU、上下文切换、RSS/PSS 与环境；不以不同语义的裸 Tokio 数字宣称语言损耗。
- HTTP/HTTPS 固定正文在更高输入速率下记录成功、错误、容量丢弃、调度落后及服务端/客户端 CPU；限速结果不宣称极限吞吐。
- TCP、WebSocket、SSE 支持有限数量的长连接保持、正文验证和多轮断开重连；记录服务端连接前、保持中、断开后的内存和 FD。
- 运行仅限自有 loopback 服务和独立预算组；所有任务、连接和进程有明确停止边界，结束无残留。执行最小定向测试，不运行全量测试、不修改全局安装、不提交。
- 不添加兼容分支、无证据的运行时重构或新依赖；发现实际阻断后再定位归属。
