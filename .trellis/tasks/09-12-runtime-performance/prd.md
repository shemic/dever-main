# 独立二进制运行性能基准

用户批准实施上一轮提出的第一阶段：常驻内存、异步调度、HTTP/HTTPS。小机器只运行已编译程序；构建资源不是本阶段优化目标。此批准取代历史网络开发阶段不运行压测的局部限制，仅限本任务拥有的有界基准。

验收：
- 根 test/ 内提供显式运行的构建与测量入口，默认测试不启动压测。
- 测量真实 Dever 编译产物，复用现有优化设置；编译不进入运行计时。
- 覆盖同步/异步/HTTP/HTTPS 空闲内存，任务启动/Channel/取消，以及 HTTP/HTTPS 固定速率请求。
- HTTP 对照使用相同 Dever runtime 的 Rust 服务和原生 Tokio/Hyper 服务；校验响应内容，记录成功、失败、未发出请求和尾延迟。
- 输出机器可读结果、环境/配置/二进制身份、CPU/RSS/PSS/线程/FD；可选独立 cgroup 限额，缺少权限时报错，不虚构限额。
- 自有随机 loopback 端口、测试证书、有界时间和负载，退出清理子进程；不访问已有服务，不跑全量测试，不提交。
- 完成短时定向验证和至少一组可解释的初始测量；长时间、多机器/多档压力矩阵明确留待显式运行。

不包含运行时优化、数据库、服务端流式请求、信号 API、TCP/WS/SSE 长连接稳定性和发行工具链。
